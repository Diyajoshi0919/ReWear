# ReWear

ReWear is a thrift and clothing exchange platform built to make it easier for people to buy, sell, and reuse pre-owned clothes.

The idea is to give unused clothes a second life instead of letting them sit unused or become waste. Users can browse available clothing items, upload their own items, and connect with others through the platform.

## Features

* User registration and login
* Browse available clothing items
* Add and manage clothing listings
* Upload product images
* View product details
* Search and explore items
* User authentication
* Backend APIs and database integration

## Tech Stack

* React.js
* Node.js
* Express.js
* MongoDB
* JavaScript
* Cloudinary
* JWT

## Purpose

ReWear focuses on promoting sustainable fashion by encouraging people to reuse clothes and making thrift shopping more accessible.
